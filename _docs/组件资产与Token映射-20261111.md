业务资产存储由 template-store.js 与 capability.js 管理；授权、个人偏好与模型检索由 asset-policy.js 汇合。模版迁移为独立记录，不改写原组件或应用；文件更新仅修改模版修订，无应用联动升级。

组件登记 tools/component-first.registry.json；行为契约 components.spec.md §27—29；验证 bash tools/check-frontends.sh。新模版页面页内样式为0、私有类白名单为空，未放宽历史基线。

修改共享控件同时核对能力列表、接口详情、模版卡片、模版详情、可用资产、应用顶栏。覆盖键盘焦点、禁用、长名称、空数据和创建人／管理员／被授权者。生产存储及检索质量等剩余问题见整改方案。

模版配置复用component.js、component-workspace.css、Float与Gen，template-bridge.js隔离模版版本仓储。卡片显示版本号；模版自身版本、复制、导出保留，只有装配及应用联动升级取消。菜单编辑打开元数据弹窗，点击卡片进入画布。
